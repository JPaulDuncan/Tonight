# Architecture Decision Records

Each ADR records one decision, the context that forced it, and the consequences
we accepted. ADRs are immutable once accepted: if a decision changes, write a new
ADR and mark the old one `Superseded by ADR-NNNN`.

| # | Title | Status |
| --- | --- | --- |
| [0001](0001-blueprint-data-layer.md) | Blueprint data layer instead of hardcoded content | Accepted (engine choice superseded by 0007) |
| [0002](0002-netcode-stack.md) | Netcode for GameObjects with a custom build-graph channel | Superseded by [0007](0007-threejs-instead-of-unity.md); the 9-byte structure channel survives |
| [0003](0003-defer-networking-to-m4.md) | Defer networking to M4, write M1–M3 command-style | Accepted |
| [0004](0004-procedural-art-pipeline.md) | All art generated by Blender Python, not hand-modelled | Accepted (export path amended by [0008](0008-headless-gltf-export.md)) |
| [0005](0005-mcp-as-build-tooling.md) | MCP servers are first-class build tooling | Accepted |
| [0006](0006-build-grid-quantisation.md) | Absolute 4 m world-aligned build grid | Accepted |
| [0007](0007-threejs-instead-of-unity.md) | three.js and TypeScript instead of Unity | Accepted |
| [0008](0008-headless-gltf-export.md) | Export glTF from Python, not from Blender | Accepted |

## Format

```
# ADR-NNNN: Title
Status · Date · Deciders
## Context      — the forces at play, including the ones pushing the other way
## Decision     — what we are doing, stated actively
## Consequences — what this costs us, honestly
## Alternatives — what we rejected and why
```
